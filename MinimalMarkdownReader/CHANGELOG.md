# 變更紀錄

MinimalMarkdownReader 各版本的變更。安裝檔與 SHA-256 請見 [GitHub Releases](https://github.com/john0925/AI-made_Gadgets/releases)（標籤 `MinimalMarkdownReader-v<版本>`）。

## 1.1.1 — 2026-11-02

- **字型名稱顯示中文：** 繁體中文介面下，字型清單以字型本身的中文名稱顯示（例如微軟正黑體、新細明體、標楷體），並依名稱排序；清單展開時可直接輸入名稱跳到該字型。只有簡體名稱的字型顯示簡體，沒有中文名稱的字型維持英文。English 介面顯示英文名稱。設定檔仍保存英文名稱，舊設定不受影響。
- **拖放只接受 Markdown：** 拖放檔案時只開啟 `.md`／`.markdown`，其他類型的檔案不會有任何反應，也不再跳出「開啟失敗」對話框；同時拖入多種檔案時只開啟其中的 Markdown 檔。

## 1.1.0 — 2026-10-30

- **分頁：** `Ctrl+O` 可多選、可一次拖放多個檔案，每份文件一個分頁。`Ctrl+Tab`／`Ctrl+Shift+Tab` 切換、`Ctrl+W` 或滑鼠中鍵關閉；右鍵選單可「關閉其他分頁」、「複製路徑」。切換分頁會回到原本的捲動位置。
- **分頁各自的版面：** 對齊、字型、字級、行距依分頁各自調整；主題與顏色全部分頁共用。☰「將目前版面設為預設」可設定新分頁使用的版面。
- **並排顯示：** 可切換單一畫面、左右並排或上下並排，拖曳分隔線調整比例（每側至少 15%），按兩下恢復各半。
- **同步捲動：** 並排時兩側可依相同距離一起捲動。
- **單一視窗：** 程式已開啟時，再開啟 `.md` 會在原視窗新增分頁並帶到前景。

## 1.0.6 — 2026-10-29

- 對齊套用到整份文件：清單、工作清單、表格與引用都會跟著靠左／置中／靠右；程式碼區塊維持靠左。
- 「關於」改為小視窗，GitHub 連結可直接點擊。

## 1.0.5 — 2026-10-29

- 「關於」內容依介面語言顯示繁體中文或英文，並附 GitHub 專案與下載連結；內容內嵌於程式中。
- README 加入下載安全說明（只從官方 Releases 下載、比對 SHA-256）。

## 1.0.4 — 2026-10-28

- **資安修正：** 先前版本的 Markdown 文件可能執行 JavaScript 並載入遠端內容。現已停用 `{...}` 自訂屬性與影片嵌入擴充，閱讀頁面加上內容安全政策（CSP），並攔截所有網路請求，只允許文件資料夾內的圖片。
- 1.0.0–1.0.3 皆受影響，未在 Releases 發布，請勿使用。
